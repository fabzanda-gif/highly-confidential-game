# Highly Confidential

A two-player asynchronous investigation game set during the Cold War.

Players are rival intelligence officers investigating the same case. They spend Action Points to interview witnesses, inspect evidence, exchange classified clues, and submit competing case theories.

## Current status

Early playable prototype under development.

## Planned features

- Mobile-first Streamlit interface
- Two-player asynchronous matches
- Hand-authored investigation cases
- Shared and private clues
- Action Point system
- Intelligence exchanges
- Random incident cards
- Early accusations and final reports
- Persistent accounts and matches with Supabase
- Optional AI narration with Groq

## First case

**Operation Cold Turkey**

Berlin, 1978. A microfilm disappears from a locked diplomatic pouch during a six-minute blackout at Hotel Europa.

Five suspects were present. Everyone has an explanation. Most of the explanations are terrible.

## Technology

- Python
- Streamlit
- Supabase — planned for authentication and persistence
- Groq — optional narration and dialogue
